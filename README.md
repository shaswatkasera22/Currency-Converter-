# Currency-Converter-
# 💱 Currency Converter Dashboard

A modern, real-time **Currency Converter Web Application** with advanced UI/UX, live exchange rates, and trend analysis.
Built using **HTML, Tailwind CSS, and JavaScript**, this project delivers a high-end dashboard experience similar to fintech platforms.

---

## 🚀 Live Features

* 🌍 Real-time currency conversion using live API
* 🔄 Swap currencies instantly
* 📊 24-hour & 7-day trend analysis
* 💡 Smart UI with glassmorphism design
* 🔔 Notification system (UI-based)
* 🌐 Dynamic currency list from API
* 📈 High/Low exchange tracking
* ⚡ Smooth animations & particle background

---

## 🧠 How It Works

The application fetches real-time currency data using the **Frankfurter API** and performs: https://currency-converter-t8gl.vercel.app/

* Conversion between currencies
* Fetching latest exchange rates
* Trend analysis based on historical data
* Dynamic UI updates based on user selection

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript (Vanilla JS)
* REST API (Frankfurter API)
* Canvas API (for animated background)
